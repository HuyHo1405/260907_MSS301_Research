# 📓 Thử Nghiệm Jupyter Notebooks

Thư mục lưu trữ các file Jupyter Notebooks (`.ipynb`) dùng cho mục đích:
- Phân tích khám phá dữ liệu (EDA - Exploratory Data Analysis).
- Thử nghiệm trực quan hóa dự đoán mô hình (Detection & OCR Visualization).
- Thử nghiệm các tham số tiền xử lý và hậu xử lý ảnh (Perspective transform, Thresholding, Binarization).

> **Lưu ý:** Trước khi commit notebook lên Git, hãy xóa output cell (`Clear all outputs`) để tránh làm phình dung lượng kho lưu trữ.
